# orthonormal set

Set of vectors that are both [[orthogonal set|orthogonal]] and unit

## Properties

> Let $S = \{ \vec{v}_{1}, \dots, \vec{v}_n \}$ be an orthonormal basis of inner product space $V$,
> Then for any $\vec{u} \in V$,
> 
> $$
> \vec{u} = \sum_{ i = 1 }^{ n } \langle \vec{u}, \vec{v}_i \rangle \vec{v}_i
> $$

# public sphere

Virtual space where individuals debate public concern

- Governed by reason
- Conclusion carries moral weight by ethical rationalism
- Important to democracy => must be fostered
- Criticism:
	- Unequal access
	- Humans not entirely rational
	- Multiple transient publics grouping different people
- 18<sup>th</sup> century: print technology
	- Newspapers
	- Journals
	- Novels
	- Standardized pagination
	- => increases literacy
	- => massively accelerates spread of ideas
	- => builds community and boosts nationalism
	- => changes perception of time
	- => changes physical spaces `e.g.` coffee houses, salons, lending libraries
	- => democratic revolution
- 20<sup>th</sup> century: mass culture
	- Media, like radio, film, TV
	- Increases control
	- More distraction
